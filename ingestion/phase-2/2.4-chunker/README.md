# Phase 2.4 - Chunker

Creates retrieval-ready chunks from Phase 2.3 cleaned documents using relevance filtering and overlap chunking.

## Run
```bash
python ingestion/phase-2/2.4-chunker/chunker.py
```

## Input
- `ingestion/phase-2/2.3-cleaner/output/cleaned-latest.json`

## Output
- `ingestion/phase-2/2.4-chunker/output/chunks-latest.json`
