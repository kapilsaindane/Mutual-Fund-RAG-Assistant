# Phase 1 - Corpus Curation and Source Governance

This phase implements corpus governance using the exact five approved URLs from Phase 0.

## Implemented Artifacts
- `source-registry.json`
- `allowlist-config.json`
- `validation-checklist.md`

## Scope Rules
- Corpus is locked to the five approved Groww URLs.
- No additional URLs are allowed.
- Allowlist validation is exact-match, not domain-only.

## Exit Criteria Mapping
- URLs are represented in registry with required metadata fields.
- Exact URL allowlist is defined for enforcement.
- Validation checklist provided for reachability/categorization sign-off.
